# Rung 4 — Explainer video (on request only)

- Write the script as rung 1 text first. Get approval before rendering.
- 60 to 120 seconds. 16:9 for lessons, 9:16 for short-form.
- Animation: Manim, or HTML/SVG captured with ffmpeg. Narration: local or free TTS. Paid TTS only with the user's key and consent. No TTS: script plus silent animation.
- "Teach" or "explain to a class" without the word video gets rung 1, plus rung 2 if there is a flow.
